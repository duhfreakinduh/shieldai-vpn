# Security Policy

## Reporting a vulnerability
Do not post secrets, browsing/network data, private URLs, credentials, exploit details, or sensitive logs in a public issue. Use GitHub private vulnerability reporting if enabled; otherwise open only a minimal issue until a private channel is established.

## Security expectations
- Never commit API keys, VPN credentials, certificates, or provider tokens.
- Do not claim traffic is encrypted/tunneled/protected unless implemented and tested.
- Treat browsing, DNS, IP, and network identifiers as sensitive.
- Do not send network/browsing data to remote AI without explicit user action and disclosure.
- Validate AI-generated security advice and clearly label simulated/demo behavior.
- Keep logs free of credentials and sensitive URLs.
